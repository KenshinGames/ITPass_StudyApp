# ITパスポート 合格ドリル

ITパスポート試験（IPA）の対策Webアプリ。「応用情報 合格ドリル」と同じ構成（ビルド不要の素の HTML/CSS/JS）で、「ゼロ知識から一発合格」を狙い、**学習講座で学んでから4択問題を解く**流れにしている。

## 主な機能

- **学習講座（学べるページ）** … 6分野×3レッスン＝18レッスン。概念・表・公式・つまずきポイントを読んでから確認テスト（6〜7問、60%以上で完了）
- **AIに質問** … 問題の解説・結果画面・レッスン画面・ホームから質問できる。問題（またはレッスンの内容）・正解・解説と質問を入れた状態で ChatGPT / Claude を新しいタブで開く。`config.js` の `CHAT_URL` に中継サーバーを設定すれば、アプリ内で回答を受け取る方式にも切り替えられる（AP版と同じ通信仕様）
- **4択テスト** … オリジナル120問（6分野×20問）
  - 今日の10問（間隔反復 1/3/7/14/30日で自動復習）
  - 分野別ドリル（全問・未回答・まちがえた問題）
  - 短縮模試（30問）
  - 本番形式の模擬試験（100問・120分。ストラテジ系35・マネジメント系20・テクノロジ系45の配分）
  - 間違えた問題・★を付けた問題の復習
- 学び方ガイド、試験日カウントダウン、効果音、文字サイズ、PWA（ホーム画面に追加・オフライン）、記録の引き継ぎコード

## 構成

- `index.html` — 本体
- `app.js` — 画面・状態管理・間隔反復・模試タイマー・AIに質問
- `questions.js` — 4択問題120問と分野（`FIELDS`）・大分類（`GROUPS`）の定義
- `lessons.js` — 学習講座18レッスンと学び方ガイドの本文
- `config.js` — AIに質問の中継先URL（空なら ChatGPT / Claude を開く）
- `style.css` — 見た目（ライト/ダーク対応）
- `sw.js` / `manifest.webmanifest` / `icons/icon.svg` — PWA（キャッシュ名 `ip-v1`）

学習記録は端末内（localStorage キー `ipstudy.v1`）に保存され、サーバーには送られない。

## 分野

| 大分類 | アプリの分野 | 本番形式模試での出題数 |
|---|---|---|
| ストラテジ系 | 企業と法務 / 経営戦略・システム戦略 | 17 + 18 = 35 |
| マネジメント系 | 開発・プロジェクト・サービス | 20 |
| テクノロジ系 | 基礎理論・コンピュータ / データベース・ネットワーク / セキュリティ | 15 + 15 + 15 = 45 |

## 試験の前提と判定

- 試験時間 120 分・100 問（四肢択一）、CBT 方式
- 合格基準：総合評価点 600/1000 以上、かつ 3 分野それぞれ 300/1000 以上（IRT 方式）
- アプリの模試は「総合正答率 60% 以上、かつ 3 分野とも 30% 以上」を合格ラインの目安として判定する
- 試験の制度・シラバスは改訂されることがあるため、受験前に IPA の公式情報を確認すること

## 問題について

- 問題・講座・解説はすべてオリジナルで、過去問の転載ではない
- 問題を足すときは `questions.js` に `Q(分野, 問題文, 正解, [誤り3つ], 解説)` を追加する。各分野の並び順が問題ID・レッスンの確認テストに対応しているため、既存の問題の途中に挿入する場合は `lessons.js` の `RANGES` も見直す

## 公開方法（GitHub Pages）

1. Settings → Pages で、このブランチのルートを公開元に設定
2. 発行された URL をスマホで開き、「ホーム画面に追加」
